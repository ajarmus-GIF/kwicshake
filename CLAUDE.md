   ## Workflow for every task
   1. Run npm install.
   2. Make the change on a new branch. Never push to main.
   3. Run npm run build and fix anything that breaks.
   4. Commit, push, and open a pull request with a short summary of what changed.
   5. Wait for the Cloudflare preview deployment to finish on the pull request, then send me the preview link in chat.
   6. Do not merge until I reply "merge it". When I do, merge the pull request into main and confirm it merged.
